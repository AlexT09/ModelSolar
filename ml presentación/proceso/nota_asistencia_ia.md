# Nota sobre asistencia de IA en este proyecto

Modelo usado en las sesiones de trabajo con Claude Code para este proyecto: **Claude Sonnet 5**
(`claude-sonnet-5`), de Anthropic. No es "Sonnet 5.5": esa versión no existe en la familia de modelos
disponible al momento de escribir esto (octubre de 2026). La familia actual de Anthropic incluye
Claude Opus 4.8, Claude Sonnet 5 y Claude Haiku 4.5.

Se deja esta nota como referencia para la sustentación y para cualquier declaración de uso de
herramientas de IA que pida el curso, dado que el profesor valora el buen uso de estas herramientas
y pidió transparencia sobre cómo se usaron, no que se oculte su uso.
