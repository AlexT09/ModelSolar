# Tarea 3: Clasificador Bayesiano en Enfermedades Cardíacas

**Asignatura:** Machine Learning  
**Dataset:** Cleveland Heart Disease (UCI Machine Learning Repository)  
**Contenido:**
- `tarea3.ipynb`: Cuaderno completo ejecutado con EDA, justificación de GaussianNB vs variables discretas/continuas, validación cruzada y comparación con regresión logística.
- `4. Clasificador Bayesiano - Machine Learning.pdf`: Guía oficial del profesor.
- `clasificador_bayesiano.md`: Análisis conceptual de probabilidades a priori, verosimilitud y a posteriori.
- `documentaci_n_del_dataset_cleveland_heart_disease.md`: Diccionario de datos y descripción de características.
- `heart+disease/`: Carpeta con los archivos originales del dataset de Cleveland.
- `scripts/`: Scripts auxiliares de generación y análisis exploratorio (`create_nb.py`, `eda_analysis.py`, `read_outputs.py`).
