# Tarea 2: Demostración de Fuga de Datos y Pipelines de Validación Cruzada

**Asignatura:** Machine Learning  
**Contenido:**
- `1_model_leakage_demo.ipynb`: Demostración empírica de cómo la fuga de información (data leakage) en preprocesamiento infla artificialmente las métricas.
- `2_model_pipeline_cv.ipynb`: Implementación de pipelines de scikit-learn con validación cruzada sin fuga.

*Nota:* La infraestructura completa de microservicios (FastAPI), contenedores (Docker), Kubernetes y CI/CD de este proyecto integrador se encuentra en la carpeta raíz `Proyecto Integrador Pipelines/`.
